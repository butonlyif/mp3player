# Soul Play 私人共鸣评价体系设计

## 目标

为歌曲增加一套区别于传统星级评分的私人评价体系。用户应能在紧凑的歌曲列表中快速识别自己与歌曲的关系，同时保持 Soul Play 克制、流动的视觉风格。

评价语义固定为四级：

| 数值 | 名称 | 含义 |
| --- | --- | --- |
| 0 | 无感 | 尚未评价或没有特别感受 |
| 1 | 有感觉 | 愿意再次聆听 |
| 2 | 共鸣 | 与歌曲建立了明显的私人连接 |
| 3 | 灵魂曲 | 对用户具有特殊意义的歌曲 |

本功能只保存用户主动给出的评价，不根据播放次数自动推测，也不提供云同步。

## 视觉语言：灵魂刻度

歌曲标题左侧设置一个极窄的刻度区域。评价越深，光痕越长、越亮：

- 无感：不显示任何光痕。
- 有感觉：短青色光痕。
- 共鸣：较长的青紫渐变光痕，带轻微柔光。
- 灵魂曲：最长的紫粉渐变光痕，带克制的辉光。

列表静止时，无感歌曲保持完全干净。鼠标悬停或键盘聚焦歌曲时，空白刻度区域淡入一条低透明度的幽灵刻度，以提示此处可评价。控件同时提供文字提示，例如“共鸣 · 点击修改”，确保信息不只依赖颜色表达。

所有歌曲列表使用同一套刻度，包括音乐库、歌单、专辑展开列表和文件夹列表。当前播放行的背景效果不得覆盖或混淆刻度。

## 标题与文件名

删除歌曲列表中独立的“文件名”列，仅保留“标题”列：

1. 有歌曲标题标签时，显示标签标题。
2. 缺少标题标签时，使用文件名补位，并移除最后一个扩展名。
3. 例如 `Song.demo.mp3` 补位显示为 `Song.demo`。

该规则只影响显示，不修改歌曲标签或文件名。

## 评价交互

点击刻度区域按以下顺序循环：

`无感 → 有感觉 → 共鸣 → 灵魂曲 → 无感`

悬停刻度区域时展开四段微型刻度，允许用户直接选择目标等级。评价控件与歌曲主体的播放点击区域分离；操作评价不得开始播放或更换当前歌曲。

更新采用乐观交互：点击后立即更新所有可见视图，再异步写入本地数据库。保存失败时恢复此前等级，并显示轻量错误提示。

## 排序

列表表头增加一个窄的“共鸣”排序入口，按三态循环：

1. 高到低：灵魂曲、共鸣、有感觉、无感。
2. 低到高：无感、有感觉、共鸣、灵魂曲。
3. 恢复进入评价排序前的排序规则。

同一评价等级内使用稳定排序，保留进入评价排序前的相对顺序。

- 音乐库和歌单：评价排序作用于当前完整列表。
- 专辑：仅在用户主动选择评价排序后，重排各专辑内部的歌曲；专辑分组顺序不变。
- 文件夹：仅重排当前文件夹直接包含的歌曲；文件夹树结构不变。
- 从已排序列表开始播放时，播放队列采用屏幕上的排序结果。
- 评价排序只改变当前视图和由该视图建立的播放队列，不修改歌曲文件、专辑曲序元数据或歌单的永久顺序。

## 数据模型与边界

在本地歌曲记录中增加整数属性 `resonance`，合法范围为 `0..=3`，默认值为 `0`。数据库升级应自动为现有记录补充默认值。

扫描器插入或更新已存在歌曲时必须保留 `resonance`，不能以扫描结果覆盖用户评价。评价属于 Soul Play 数据库，不写入 MP3 标签。音乐库、歌单、专辑和文件夹视图引用同一歌曲评价源，因此任一视图的修改必须同步反映到其他视图。

后端提供针对单首歌曲更新评价的命令，并在写入前校验歌曲存在及数值范围。前端 API 只暴露明确的共鸣等级类型，避免任意整数进入 UI 状态。

若歌曲因文件缺失被数据库清理，之后又作为新记录重新加入，第一版不承诺恢复旧评价。

## 组件边界

- `ResonanceMark`：只负责四级视觉、悬停直选、循环切换及可访问性文本。
- 排序逻辑：以纯函数计算三态排序，保证稳定性，并由各列表视图复用。
- 状态层：负责乐观更新所有歌曲引用，失败时回滚。
- API 与 Tauri 命令：负责把合法等级持久化到数据库。
- 数据库层：负责迁移、读取、更新，以及扫描时保留评价。

刻度组件不直接操作数据库；列表组件不自行复制持久化逻辑。

## 错误处理

- 非法等级：后端拒绝并返回明确错误。
- 歌曲已被删除：回滚界面评价，并提示刷新音乐库。
- 普通写入失败：恢复此前等级，当前播放不中断。
- 排序过程中评价变化：立即按当前排序方向重新定位该歌曲，并保持稳定排序规则。

## 测试范围

### 数据库与后端

- 旧数据库升级后所有歌曲默认无感。
- 四个合法等级可写入并正确读取。
- 非法等级被拒绝。
- 重新扫描现有歌曲不会清空评价。

### 状态与排序

- 四级循环及直接选择正确。
- 乐观更新成功后保持，失败后完整回滚。
- 高到低、低到高、恢复原排序三态正确。
- 同等级稳定排序。
- 专辑和文件夹排序不破坏分组边界。
- 已排序视图生成相同顺序的播放队列。

### 界面

- 无感在静止状态不显示光痕，悬停或聚焦时显示幽灵刻度。
- 三个有评价等级具有可区分的长度、颜色和文字标签。
- 点击评价不会触发播放行事件。
- 所有列表视图共享评价状态。
- 标题缺失时正确使用去扩展名的文件名补位。

## 非目标

第一版不包含半级评价、自动评价、按情绪多标签、评价历史、批量评价、云同步、将评价写回音频标签或独立的“灵魂曲”智能歌单。后续可基于真实使用情况单独设计。
