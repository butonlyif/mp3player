# Soul Play 品牌与上下文播放队列设计

## 目标

将应用统一更名为 **Soul Play**，以“灵魂涟漪”为正式图标方向；同时让专辑与文件夹视图天然成为各自有边界的播放队列，避免下一首跳回整个音乐库。

## 品牌名称

- HTML 页面标题、自定义标题栏、Tauri `productName` 与主窗口标题统一改为 `Soul Play`。
- npm 包名改为 `soul-play`，不影响代码模块结构。
- 保留 Tauri identifier `com.lumen.player`，以延续现有应用身份、数据库和用户设置。
- 不修改内部数据库文件名及协议名；它们属于兼容性实现细节，不在用户界面出现。

## 图标设计

采用已确认的 A「灵魂涟漪」方向：

- 深蓝黑圆角方形底板，适合当前暗色、玻璃与氛围光界面。
- 三层略微不规则的椭圆涟漪，表达声音、记忆与情绪向内外扩散。
- 中心使用明亮灵核作为小尺寸视觉锚点。
- 光色由青蓝过渡到紫色，边缘加入克制的玫红，延续播放器现有液态记忆色彩。
- 图标中不放文字、字母或传统播放三角，避免缩小时模糊并提高品牌独特性。
- 生成 1024×1024 正方形母版，再通过 Tauri 图标工具生成 PNG、ICO、ICNS、Windows 与移动平台尺寸。

## 上下文播放队列

### 音乐库表格

维持现有行为：双击歌曲时，当前经过搜索与排序后的可见列表成为播放队列。

### 专辑视图

- 双击专辑内歌曲时，仅该专辑的歌曲进入队列。
- 队列按碟号、曲号、文件名稳定排序；缺少标签的歌曲排在有标签歌曲之后。
- 当前搜索条件继续生效，搜索结果中不可见的歌曲不进入队列。

### 文件夹视图

- 双击歌曲时，仅歌曲所在的当前层文件夹成为队列。
- 不递归包含子文件夹；进入子文件夹播放时，以该子文件夹为新的队列边界。
- 队列沿用当前文件夹中显示的稳定顺序。

### 播放控制

下一首、上一首、顺序播放、随机播放和 Crossfade 全部使用已建立的上下文队列。到达专辑或文件夹队列末尾时，遵循当前播放模式，不回退到音乐库大队列。

## 代码边界

- `AlbumMode` 和 `FolderNode` 的播放回调由只传曲目改为同时传曲目与所属队列。
- `LibraryView` 仍是唯一调用 Zustand `playTrack(track, queue)` 的位置，分组组件不直接依赖全局 Store。
- 图标母版作为项目资产保留，平台派生图标统一放在 `src-tauri/icons`。

## 验证

- 为专辑队列排序、文件夹队列边界及回调队列内容增加单元测试。
- 运行全量 Vitest 与生产构建。
- 检查 Tauri 配置中的名称与图标路径完整性。
- 在 Cargo 可用时运行 Tauri 图标生成和原生构建；若本机仍无 Cargo，则使用已安装的 Tauri CLI 图标命令并明确记录原生构建限制。
